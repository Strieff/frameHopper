This is **FrameHopper** - a tremendous, fantastic, extraordinary tool to review, grade and analyze (animated) videos

This app uses FFmpeg. See [ffmpeg readme](ffmpeg/readme.md) for additional details

This application uses Plotly.js 3.6.0, which is loaded from the Plotly CDN at runtime. Plotly.js is not bundled with or distributed with this application.
If you wish to use your own version of Plotly.js for offline use, download the **plotly-3.6.0.min.js** file from [Plotly's website](https://plotly.com/javascript/getting-started/#download) and put it in plotly folder next to the application.

This project uses third-party icons. See [attributions file](attribution.md) for details.

When running swagger is available at http://localhost:8080/swagger-ui/index.html
